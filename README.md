# D1 Save Forge — build artifact

Live application: https://samuelecioni.github.io/d1-save-forge-web/

This repository is a one-way build output of
[d1-save-forge](https://github.com/samuelecioni/d1-save-forge). It is
regenerated from a clean build on every deploy and carries the source
commit it was built from in `version.json`. It keeps no history and
accepts no pull requests; report issues against the source repository.
